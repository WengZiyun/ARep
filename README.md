# ARep

This repository contains the code and selected data artifacts for:

**An Adversarially Secure Reputation Mechanism for Trustless AI Agent Interactions in Blockchain Networks**

The repository includes implementation and experiment code for the ARep reputation mechanism, related evaluation scripts, selected datasets, and agent-risk screening components used in the study.

## Repository Contents

- `C_reputation/`: reputation construction stages.
- `D_RQ1/`: evaluation scripts and agent-risk screening experiments.
- `E_RQ2/`: comparative reputation experiments.
- `4_ARep/`: ARep stage modules required by the released code.
- `data/`: selected released data files.
